# Cyclop для Windows

Панель вверху экрана: задержите курсор на тонкой полоске по центру — и
раскроются музыка, полка файлов, история буфера обмена, заготовки, календарь,
перевод, конвертер валют, заметки, суфлёр и скриншоты. Убрали курсор —
панель свернулась.

Windows 10 (2004+) и 11, x64 и ARM. Один файл, без установки.

## Скачать

**Сайт: https://cyclop.cyclop-updates.workers.dev** — кнопка «Скачать»
сама выберет нужную версию.

Или со страницы
[релизов](https://github.com/shoxruxTatu/cyclop-windows/releases):
`Cyclop-win-x64.exe` для обычных ПК, `Cyclop-win-arm64.exe` для Windows на
ARM. Дальше программа обновляется сама.

При первом запуске Windows может показать «Windows защитила ваш компьютер» —
нажмите «Подробнее» → «Выполнить в любом случае»: exe пока не подписан.

Подробно о вкладках, скриншотах, файлах и сборке — в
[windows/README.md](windows/README.md).

## Откуда это

Windows-версия основана на [Cyclop для macOS](https://github.com/akalikbergenov/cyclop)
Адиля Калыкбергенова (лицензия MIT): тот же дизайн и те же идеи, переписано
на C# / WPF. Исходный macOS-проект лежит в этом же репозитории
(`Sources/`, `Resources/`, `docs/`).
