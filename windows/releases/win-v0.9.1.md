Первая версия Cyclop для Windows.

Задержите курсор на тонкой полоске вверху по центру экрана — раскроется панель:

- **Музыка** — что играет в Windows (Spotify, браузер, «Медиаплеер»): обложка, перемотка, кнопки. Клик по обложке открывает окно, где играет звук.
- **Полка** — перетащите файлы внутрь и наружу; скриншоты попадают сюда сами.
- **Буфер** — последние 40 копирований.
- **Заготовки, заметки, суфлёр, валюта, перевод, календарь** (по iCal-ссылке).
- **Скриншоты** — Ctrl+Alt+A: область (левая кнопка — сразу в буфер, правая — редактор со стрелками, текстом и маркером); Ctrl+Alt+S — весь экран. Сочетания меняются в настройках.
- **Блокировка клавиатуры** — чтобы протереть клавиши и экран.

Дальше программа обновляется сама. Анонимный подсчёт пользователей (случайный номер установки, без личных данных) выключается в Настройках → Обновления.

**Какой файл скачать:** `Cyclop-win-x64.exe` — для обычных ПК, `Cyclop-win-arm64.exe` — для Windows на ARM. При первом запуске SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».
