# Cyclop для Windows

Порт Cyclop на Windows 10 (2004+) и 11. Вверху по центру каждого экрана
лежит тонкая чёрная полоска; если задержать на ней курсор, вниз раскрывается
та же панель, что и под чёлкой MacBook. Курсор ушёл — панель свернулась.

Написано на C# / WPF (.NET 8). Сторонних зависимостей нет, только .NET и
Windows API.

## Обновления и приватность

Сборки из релизов на GitHub обновляются сами: проверяют сервер обновлений
раз в 6 часов, скачивают новую версию, сверяют SHA-256 и перезапускаются.
Заодно они анонимно сообщают о себе, чтобы автор видел число пользователей:
случайный номер установки, версию программы и Windows — больше ничего.
Подсчёт выключается в Настройках → Обновления, обновления при этом
остаются. Как это устроено и как выпускать версии — в
[RELEASING.md](RELEASING.md). Exe, собранные локально, никуда не обращаются.

## Запуск

Готовые сборки лежат в `dist/`: это один самодостаточный `Cyclop.exe`,
ставить .NET не нужно.

- `dist/win-x64/Cyclop.exe` — обычные ПК;
- `dist/win-arm64/Cyclop.exe` — Windows на ARM (Snapdragon).

Exe не подписан, поэтому при первом запуске SmartScreen покажет «Windows
защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

Повторный запуск exe, пока Cyclop уже работает, возвращает значок в трей
(если его выключили в настройках) и открывает панель.

## Что где

| Вкладка | Как сделано на Windows |
|---|---|
| Музыка | Системные медиасессии (те же, что во всплывашке громкости): Spotify, «Медиаплеер», видео во вкладке браузера. Обложка, перемотка, кнопки |
| Полка | Перетаскивание файлов внутрь и наружу, Ctrl-клик — выбрать несколько. Клик копирует файл в буфер |
| Буфер | Последние 40 копирований. Записи, помеченные менеджерами паролей как «не для истории», пропускаются |
| Заготовки | `snippets.json` — тот же формат, что на Mac |
| Календарь | **По iCal-ссылке** (см. ниже). Кнопка «Подключиться» для Zoom, Meet, Teams и др. |
| Перевод | Английский ↔ русский. **Онлайн**, через Google Переводчик (см. ниже) |
| Валюта | Тот же источник курсов, что на Mac |
| Заметки, Суфлёр | Как на Mac |
| Утилиты | Скриншоты (см. ниже) и блокировка клавиатуры и мыши, чтобы протереть их и экран |
| Настройки | Автозапуск, значок в трее, задержка открытия, вкладки, дисплеи, скриншоты, календари |

### Скриншоты

- **Область** — по умолчанию **Ctrl+Alt+A**. Экран замирает и затемняется.
  Выделили **левой** кнопкой — область сразу в буфере обмена. Выделили
  **правой** — открывается редактор: карандаш, линия, стрелка, прямоугольник,
  маркер, текст, выбор цвета, отмена (Ctrl+Z); справа внизу — копировать
  (Ctrl+C или Enter), сохранить в файл (Ctrl+S), закрыть (Esc).
- **Весь экран** — по умолчанию **Ctrl+Alt+S**: дисплей, на котором курсор,
  сразу в буфер.

Сочетания меняются в Настройках → Скриншоты: клик по полю и нажать новое,
Backspace — выключить. Если сочетание уже занято другой программой, поле
станет жёлтым. Оба действия есть и в трее, и на вкладке «Утилиты».
Каждый снимок, как и Win+Shift+S, сохраняется в `Изображения\Cyclop` и
попадает на полку.

Значок в трее: открыть панель, «Скрывать содержимое» (режим приватности по
разделам) и выход.

Скриншоты, снятые в буфер (Win+Shift+S), сохраняются в
`Изображения\Cyclop` и кладутся на полку. По желанию можно следить за
папкой `Изображения\Снимки экрана`, куда пишет Win+PrintScreen.

### Чем отличается от macOS-версии

- **Календарь.** Обычному (не из Microsoft Store) приложению Windows не даёт
  читать системный календарь, поэтому Cyclop берёт ту ссылку, которую
  календарь и так публикует: в Google Календаре — «Настройки → ваш
  календарь → Закрытый адрес в формате iCal», в Outlook.com — «Параметры →
  Общие календари → Опубликовать → ICS». Ссылка добавляется в Настройках →
  Календари. Поддерживаются повторяющиеся встречи, исключения и перенесённые
  экземпляры, часовые пояса.
- **Перевод.** Встроенного офлайн-переводчика, которым может пользоваться
  приложение, в Windows нет. Текст из вкладки отправляется в публичный API
  Google Переводчика (если он не ответит — в MyMemory); под полем это написано.
- **Блокировка клавиатуры** не требует разрешений, но Ctrl+Alt+Del и Win+L
  пропускает всегда — их Windows не отдаёт никому.
- Нет «высокой чёлки»: на Windows всегда тонкая полоска. Над полноэкранным
  приложением (игра, видео, F11) полоска прячется и не реагирует.

## Файлы

Всё своё Cyclop хранит в `%APPDATA%\Cyclop`:

- `config.json` — настройки (переносимы между ПК; ключи совпадают с
  macOS-версией там, где смысл тот же);
- `snippets.json`, `notes.json`, `teleprompter.txt`;
- `state.json` — полка, выбранная пара валют и случайный номер установки;
- `log.txt` — журнал: какие медиасессии видит Windows, ошибки сети и т. п.;
- `CalendarCache\` — последние загруженные календари, чтобы панель показывала
  встречи сразу после запуска и без сети.

## Сборка

Нужен .NET 8 SDK. Собирается и на Windows, и на macOS/Linux
(`EnableWindowsTargeting`), но запускается, понятно, только на Windows.

```bash
dotnet test windows/Cyclop.Core.Tests
```

```bash
dotnet publish windows/Cyclop -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -p:DebugType=none -o windows/dist/win-x64
```

```bash
python3 windows/check-strings.py
```

То же самое делает `.github/workflows/windows.yml` на каждый пуш в `windows/`.

### Устройство

- `Cyclop.Core` — всё, что не зависит от Windows: хранилища, формат
  `snippets.json`/`config.json`, разбор iCal и правил повторения, валюты,
  перевод, локализация. Покрыто тестами (`Cyclop.Core.Tests`).
- `Cyclop/Panel` — окно панели и контроллер. Окно одно, прозрачное, поверх
  всех и никогда не забирает фокус само; на время ввода в поле оно берёт
  клавиатуру и при сворачивании возвращает её окну, у которого взяло.
  Положение курсора опрашивается таймером, как и на Mac.
- `Cyclop/Panes` — по файлу на вкладку. Интерфейс собран кодом, без XAML.
- `Cyclop/Services` — медиасессии, буфер обмена, полка, скриншоты,
  блокировка ввода, автозапуск.
- Русские строки — `Cyclop.Core/Strings.ru.strings`, начатый с
  `Resources/ru.lproj/Localizable.strings` macOS-версии; ключи — английский
  текст, как там.
